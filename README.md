# Створення текстового редактора у стилі «Блокнот»

## Notepad Clone (C++)

Проєкт являє собою графічний текстовий редактор, створений мовою C++ із використанням WinAPI та компонента RichEdit. Програма відтворює базовий функціонал «Блокнота» та має розширені можливості форматування тексту.

Редактор працює у віконному режимі та дозволяє користувачу створювати, редагувати та зберігати текстові файли з підтримкою додаткових інструментів оформлення.

---

## Технологічний стек

* **Мова програмування:** C++   
* **API:** WinAPI (Windows.h)
* **Текстовий компонент:** RichEdit (Msftedit.dll)
* **Робота з файлами:** WinAPI (CreateFile, ReadFile, WriteFile)
* * **Контейнери:** std::vector
* **Робота зі строками:** std::wstring


---

## Мета проєкту

Метою проєкту є розробка настільного текстового редактора з графічним інтерфейсом, який дозволяє користувачу створювати, відкривати, редагувати та зберігати текстові файли у зручному середовищі. Додатково реалізовано інструменти форматування тексту, зміну зовнішнього вигляду програми та розширені можливості редагування, що наближають застосунок до функціональності простого сучасного текстового редактора.

---

## Основні можливості

* Відкриття текстових файлів (.txt)
* Збереження текстових файлів у форматі UTF-8
* Створення нового документа
* Редагування тексту в багаторядковому режимі
* Копіювання, вирізання та вставка тексту
* Скасування останньої дії (Undo)
* Виділення всього тексту
* Зміна кольору тексту
* Зміна розміру шрифту (A+ / A-)
* Підтримка світлої та темної теми
* Автоматична нумерація рядків у різних стилях (1), 1., 1.1)
* Гарячі клавіші для швидкого доступу:
* Ctrl+S — збереження
* Ctrl+O — відкриття файлу
* Ctrl+N — новий документ
* Ctrl+C / Ctrl+V / Ctrl+X — редагування
* Ctrl+Z — скасування дії
