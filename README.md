Створення текстового редактора у стилі «Блокнот»
Notepad Clone (C)
Консольний застосунок, розроблений мовою C, що відтворює основний функціонал текстового редактора «Блокнот» — відкриття, редагування та збереження текстових файлів.
---

Технологічний стек

Мова програмування: C (стандарт C99)
Робота з файлами: stdio.h
Динамічна пам'ять: malloc/realloc
Платформа: Linux / Windows
---


Мета проєкту
Розробка простого текстового редактора з консольним інтерфейсом, який дозволяє користувачу відкривати, редагувати та зберігати текстові файли у зручному середовищі без зайвих залежностей.
---

Основні можливості

відкриття та збереження текстових файлів (.txt)
введення, видалення та редагування тексту
навігація курсором (стрілки, Home, End, Page Up/Down)
нумерація рядків — відображення номера кожного рядка зліва
пошук рядка у тексті (Ctrl+F)
заміна тексту (Ctrl+H) — знайти всі входження і замінити на інше слово
копіювання, вирізання та вставка (Ctrl+C / X / V)
скасування та повторення дій (Ctrl+Z / Ctrl+Y)
лічильник слів і символів у статус-рядку в реальному часі
відображення позиції курсора та імені файлу у статус-рядку
---


Примітки
Проєкт підготовлений з урахуванням можливості подальшого розширення, зокрема додавання графічного інтерфейсу на основі WinAPI або GTK.
